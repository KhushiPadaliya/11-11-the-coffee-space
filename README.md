# The Coffee Space — React Web Application

A modern, responsive, and artisanal specialty coffee roastery web application built with **React** and **Vite**, styled with a custom design system featuring **Forest Green (#2F3E2E)**, **Sage Green (#A3B18A)**, **Warm Caramel (#DDA15E)**, **Cream (#F5F1E8)**, and **Dark Coffee (#2B2118)**.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## ☕ Key React Features & Components

- **`Navbar.jsx`**: Sticky header with scroll detection, active section indicator, and slide-out mobile drawer.
- **`VinylVibeBar.jsx`**: Rotating turntable animation with the current playing track in the cafe.
- **`Hero.jsx`**: Real-time operating hours calculator badge that computes open/closed status every minute.
- **`Highlights.jsx`**: 4 craft pillar cards with sage green icons.
- **`AboutStory.jsx`**: Narrative story, milestone metric counters, and team polaroids with personal barista quotes.
- **`MenuSection.jsx`**: Category tabs, real-time search filtering, dietary filter pills, and price formatting via `Intl.NumberFormat`.
- **`FlavorFinderQuiz.jsx`**: Interactive drink flavor match quiz with custom recommendation quotes.
- **`CupCustomizerModal.jsx`**: Interactive drink builder (size, plant milks, temperature, extra shot) with live price calculation.
- **`GallerySection.jsx`**: Filterable 4-column aligned photo grid with fullscreen keyboard-accessible Lightbox.
- **`LocationHours.jsx`**: Weekly schedule with current day highlighted, amenities chips, and Google Maps embed.
- **`ContactSection.jsx`**: FAQ accordion and validated table reservation booking form.
- **`ReservationModal.jsx`**: Confirmation dialog with unique confirmation code.
- **`Toast.jsx`**: Polite accessible notification system.
